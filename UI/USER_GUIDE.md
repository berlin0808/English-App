# Hướng dẫn sử dụng Quick Vocab Trainer

Chào bạn! Đây là ứng dụng học từ vựng tiếng Anh đơn giản, dễ dùng, phù hợp cho việc ghi chép và ôn tập từ mới mỗi ngày.

## 1. Mục đích của app
App này giúp bạn:
- ghi lại từ vựng mới
- xem lại nghĩa của từ
- làm quiz để ôn tập
- viết câu với từ mới
- theo dõi tiến độ học tập

## 2. Cách mở app
1. Mở thư mục UI
2. Nhấp đúp vào file index.html
3. Trình duyệt sẽ mở app cho bạn

Bạn không cần đăng ký tài khoản hay cài đặt gì thêm.

## 3. Các tính năng chính

### a) Quick Add
Đây là nơi bạn thêm từ mới nhanh nhất.

Bạn điền các thông tin:
- Word: từ vựng
- Meaning: nghĩa của từ
- Example: câu ví dụ
- Source: nơi bạn gặp từ đó

Sau đó bấm Save Word.

Cách dùng đơn giản:
- Khi bạn đọc sách, báo, video hoặc gặp từ mới
- Ghi ngay vào app
- Sau đó học lại sau

### b) Word List
Ở đây bạn xem toàn bộ từ đã thêm.

Bạn có thể:
- tìm kiếm từ bằng thanh search
- xem nghĩa, ví dụ và nguồn gốc từ
- xóa từ nếu không cần nữa

### c) Quiz
Đây là phần ôn tập.

Bạn có thể chọn:
- Word -> Meaning: nhìn từ, chọn nghĩa
- Meaning -> Word: nhìn nghĩa, chọn từ

Sau khi làm quiz, bạn sẽ thấy:
- câu trả lời đúng/sai
- điểm số
- kết quả tổng thể

### d) Write
Đây là phần luyện viết câu.

Bạn sẽ thấy một từ ngẫu nhiên và phải viết một câu dùng từ đó.

App sẽ cho bạn phản hồi đơn giản về:
- ngữ pháp
- tự nhiên của câu
- cách viết tốt hơn

### e) Progress
Đây là phần thống kê tiến độ học.

Bạn có thể xem:
- tổng số từ đã thêm
- số từ đã thuộc
- tỷ lệ đúng khi làm quiz
- streak học tập

### f) Settings
Đây là phần cài đặt.

Bạn có thể:
- chọn số câu trong quiz
- bật/tắt tính năng AI feedback
- xuất dữ liệu ra file JSON
- nhập dữ liệu từ file JSON
- xóa dữ liệu nếu cần

## 4. Cách thêm dữ liệu học
Có 2 cách:

### Cách 1: Thêm thủ công bằng Quick Add
Dùng khi bạn muốn thêm vài từ mỗi ngày.

Các bước:
1. Vào tab Quick Add
2. Nhập từ mới
3. Nhập nghĩa
4. Có thể thêm ví dụ và nguồn
5. Bấm Save Word

### Cách 2: Nhập nhiều từ cùng lúc bằng file JSON
Dùng khi bạn có nhiều từ cần nhập.

1. Mở file sample-vocabulary.json
2. Thêm các từ theo mẫu có sẵn
3. Vào Settings
4. Chọn Import Data
5. Chọn file JSON

## 5. Cách backup dữ liệu
Nếu bạn muốn giữ dữ liệu an toàn:
1. Vào Settings
2. Nhấn Export Data
3. File JSON sẽ được tải xuống
4. Bạn có thể lưu vào máy hoặc ổ đĩa

## 6. Cách chuyển sang máy khác
Nếu muốn dùng app trên máy khác:
1. Copy thư mục UI sang máy mới
2. Mở file index.html
3. Nếu cần giữ dữ liệu cũ, hãy dùng Export Data và Import Data

## 7. Mẹo dùng app hiệu quả
- Mỗi ngày thêm 3–5 từ mới
- Làm quiz ít nhất 1 lần mỗi ngày
- Viết câu với từ mới để ghi nhớ lâu hơn
- Backup dữ liệu định kỳ

## 8. Lưu ý quan trọng
- Dữ liệu được lưu trong trình duyệt của bạn
- Nếu bạn xóa dữ liệu trình duyệt thì dữ liệu có thể bị mất
- Vì vậy hãy thường xuyên export dữ liệu ra file JSON

## 9. Tóm tắt nhanh
- Quick Add: thêm từ mới
- Word List: xem danh sách từ
- Quiz: ôn tập
- Write: luyện viết câu
- Progress: xem tiến độ
- Settings: cài đặt và backup

Nếu bạn muốn, tôi có thể viết tiếp một phiên bản hướng dẫn ngắn gọn hơn để bạn dán vào README hoặc gửi cho người khác dùng.
