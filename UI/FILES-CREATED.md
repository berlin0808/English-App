## 🎓 How to Get Started (5 Steps)

### Step 1: Open App (1 min)
```
1. Go to: My app/UI/ folder
2. Double-click: index.html
3. Opens in: Your default browser
4. Ready! ✨
```

### Step 2: Add Words (5 min)
```
1. Click: 📝 Quick Add tab
2. Type: word, meaning
3. Click: 💾 Save Word
4. Repeat: Add 5+ words
```

### Step 3: Take Quiz (10 min)
```
1. Click: 🧠 Quiz tab
2. Choose: "Word → Meaning"
3. Click: Start Quiz
4. Answer: 10 questions
5. See: Your score!
```

### Step 4: Practice Writing (10 min)
```
1. Click: ✍️ Write tab
2. Click: Start Writing Practice
3. Write: Sentence with word
4. Click: Check Sentence
5. Learn: From feedback
```

### Step 5: Backup Data (2 min)
```
1. Click: ⚙️ Settings tab
2. Click: 📥 Export Data
3. Save: Your backup file
4. Keep: In safe place
```
